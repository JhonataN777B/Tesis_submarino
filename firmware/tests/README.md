# Pruebas unitarias de hardware

Cada carpeta contiene un sketch independiente. Conecte únicamente el elemento bajo prueba, verifique alimentación común y confirme el pin en `../../hardware/pin_map.md` antes de cargarlo.

| Carpeta | Elemento |
| --- | --- |
| `aro_led` | Aro NeoPixel |
| `blink_led` | LED básico |
| `bombas` | Bombas de agua |
| `bombas_aro_led` | Prueba combinada de bombas y aro LED |
| `garra_v1`, `garra_v2` | Servo de pinza |
| `sensor_voltaje` | Medición de batería |
| `sensor_magnetico` | Sensor magnético |
| `sensor_presion` | Sensor de presión |
