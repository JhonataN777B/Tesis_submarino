# Evidencia visual y archivos de fabricación

Este directorio reúne material de referencia visual localizado en `Proyecto`.

## Fotos y videos del proyecto

Los archivos originales están en [`imagenes_proyecto`](imagenes_proyecto/). Se conservaron sus nombres de origen para facilitar la comparación con `Proyecto/Imagenes`.

## Pruebas de PCB

En [`pcb`](pcb/) se incluyen `DATOS.jpeg`, `Montaje.jpeg` y `Video _Prueba.mp4`, copiados desde `Proyecto/pruebas PCB`.

## Archivos técnicos complementarios

- [`../../hardware/pcb`](../../hardware/pcb/): BOM y paquete Gerber de la PCB.
- [`../../hardware/Pieza_frontal.stl`](../../hardware/Pieza_frontal.stl) y [`../../hardware/Pieza_trasera.stl`](../../hardware/Pieza_trasera.stl): piezas para impresión 3D.
- `Proyecto/Inventor` contiene modelos CAD nativos de Inventor y `Proyecto/blender/Turbina.blend` el modelo Blender. Permanecen en la carpeta fuente.

Los archivos visuales originales se incluyen como evidencia documental; su presencia no implica que cada foto o video sea una prueba validada del funcionamiento.
