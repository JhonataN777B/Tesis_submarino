# Datos

telemetria_ejemplo.csv es una muestra ilustrativa (no resultados experimentales) con el esquema actual de 27 columnas: tres metadatos de sesion y 24 campos de telemetria.

Los CSV completos se generan durante cada ejecucion de interface/solo_control.py en interface/Logs_Submarino y tienen una copia espejo en Respaldo. Los logs crudos de sesiones y las grabaciones de HUD no se versionan; solo se conservan en el repositorio las evidencias seleccionadas bajo docs/evidencia/operacion.
