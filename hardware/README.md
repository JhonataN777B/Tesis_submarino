# Hardware

- `pcb/BOM_Tesis_2026-08-29.csv`: lista de materiales exportada del diseño.
- `pcb/Gerber_Tesis_PCB_Tesis_2026-08-29.zip`: paquete Gerber para fabricación.
- `pin_map.md`: asignación actual de GPIO del ESP32-S3.

Los modelos CAD, STL, Blender y archivos de simulación se conservan fuera del repositorio por tamaño. Antes de fabricar, confirme que el BOM, Gerbers y mapa de pines corresponden a la misma revisión.
