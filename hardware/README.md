# Hardware

## PCB

- pcb/BOM_Tesis_2026-08-29.csv: lista de materiales exportada del diseno.
- pcb/Gerber_Tesis_PCB_Tesis_2026-08-29.zip: paquete Gerber para fabricacion.
- pin_map.md: asignacion de GPIO del ESP32-S3.

## Modelos STL usados para impresion

- Pieza_frontal.stl y Pieza_trasera.stl: piezas frontal y trasera.
- soporte_garra.stl: soporte de la pinza.
- soporte_motor.stl: soporte del motor.
- soporte_1.stl, soporte_2.stl y soporte_3.stl: soportes complementarios.

Estos son exportes STL para fabricacion. Los archivos CAD editables, el proyecto de Inventor/Blender y simulaciones se conservan en las carpetas de trabajo originales.
